# CareerAI: AI-Powered Career Recommendation Web Application

A collaborative Computer Engineering graduation project developed at OSTİM Technical University. CareerAI is designed to help users explore career options through resume analysis, career recommendations, and job search.

## Project features

- User registration and profile
- Resume upload and skills analysis
- Career assessment and recommendations
- Job search and listings

*Keep only the features that are present in the version of the project in this repository.*

## Technologies

- **Frontend:** React, TypeScript, Vite
- **Backend:** Django REST Framework
- **Database:** SQLite
